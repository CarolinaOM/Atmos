# 🌤️ Atmos — Aplicación del Clima y Previsión Meteorológica

Una aplicación web moderna para consultar el clima actual y la previsión meteorológica de cualquier ciudad en tiempo real, construida con React y CSS con un diseño elegante estilo *glassmorphism* (cristal esmerilado) en tonos azules.

🔗 **Ver Proyecto en Vivo**
*(Próximamente desplegado en Netlify)*

---

## ✨ Características Principales

- **Diseño Responsivo:** Visualización optimizada para dispositivos móviles, tabletas y computadoras.
- **Búsqueda Dinámica:** Búsqueda rápida de ciudades de todo el mundo en tiempo real.
- **Clima Actual:** Muestra la ciudad, temperatura actual, condición meteorológica e icono explicativo.
- **Detalles Meteorológicos:** Información adicional clave como porcentaje de humedad, velocidad del viento y sensación térmica.
- **Previsión Extendida:** Pronóstico del clima para los próximos 5 días con temperaturas e iconos visuales.
- **Diseño Moderno:** Interfaz limpia con tarjetas translúcidas, esquinas redondeadas y tipografía moderna.

---

## 🛠️ Tecnologías Utilizadas

- **Framework:** React v18+
- **Herramienta de construcción:** Vite
- **Estilos:** CSS3 Puro (Flexbox, Grid, variables CSS y efectos de transparencia)
- **API (En progreso):** OpenWeatherMap API *(para la consulta de datos en tiempo real)*
