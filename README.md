# Atmos

Weather application built with React, Vite, and OpenWeatherMap API. Features real-time atmospheric data, dynamic weather backgrounds, and interactive tile maps.

## Features

- **Current Weather Details:** Real-time temperature, feels like, humidity, pressure, visibility, wind speed, and UV index.
- **Interactive Weather Map:** Layer overlays for rain, clouds, temperature, and wind using Leaflet and CARTO basemaps.
- **Extended Forecast:** Hourly and daily forecast breakdowns.
- **Dynamic UI:** Glassmorphism UI with context-aware atmospheric background imagery.
- **Geolocation Support:** Automatic detection of user location with fallback search.

## Tech Stack

- **Frontend:** React 18, Vite
- **Styling:** CSS Modules, Framer Motion, Lucide Icons
- **Maps:** React Leaflet, Leaflet
- **Data Source:** OpenWeatherMap API
